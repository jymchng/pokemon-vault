# Pokémon Vault — User Journeys (Guide)

Walkthrough guides for every journey a visitor can take through the Pokémon
Vault storefront, illustrated with screenshots captured from the **local dev
environment** (`http://localhost:3000`).

> All data shown in the screenshots is real backend data from the dev
> PostgreSQL database (`pokemon_vault_dev`). There are no mock screenshots.

## Test user (dev environment)

The screenshots use a pre-created test account:

| Field | Value |
|---|---|
| **Email (username)** | `test@vault.io` |
| **Password** | `Str0ng!Passw0rd` |
| **Role** | `CUSTOMER` |

You can create your own account in the sign-in modal (see
[Create an account and sign in](03-create-account-and-sign-in.md)), or reset
the test user's data with:

```bash
# clear the test user's cart + wishlist (keep the account)
TOKEN=$(curl -s -X POST http://localhost:3001/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"email":"test@vault.io","password":"Str0ng!Passw0rd"}' \
  | python3 -c "import json,sys; print(json.load(sys.stdin)['data']['accessToken'])")
curl -s -X DELETE http://localhost:3001/api/v1/cart/items -H "Authorization: Bearer $TOKEN"
```

## Re-capturing the screenshots

The screenshots were generated by `docs/user-journeys/capture.cjs` against a
running dev stack:

```bash
./scripts/dev-env.sh up
node docs/user-journeys/capture.cjs
# → writes PNGs to docs/user-journeys/images/
```

Screenshots are numbered in journey order and live in
[`images/`](images/).
